1. Executive Summary & Problem Scenario

Students and organizational treasurers handle dozens of supermarket receipts, utility invoices, and cafe bills. Manual data entry into spreadsheets is slow and prone to typographical errors.

Receipt Scanner is a full-featured personal expense tracking mobile application built with Flutter 3.x that executes on-device AI optical character recognition (OCR) using Google ML Kit. Text extraction completes in under 100 milliseconds completely offline without network latency, API tokens, or server costs. A custom multi-pass regex heuristic engine parses monetary amounts in Vietnamese Dong (VND) and USD, dates (DD/MM/YYYY), and merchant names. Users can edit values on an interactive review screen before persisting into a local SQLite database. Visual analytics are rendered via custom animated canvas painters without third-party chart dependencies.

3. System Architecture & Component Design

The codebase follows a modular clean architecture separating Presentation, Domain/Service, and Data persistence layers:

[Physical Receipt] → [Camera Viewfinder + Tap Focus] → [Isolate Image Crop]
↓
[Google ML Kit Text Recognition (On-Device)] → [Raw OCR String Buffer]
↓
[Heuristic Regex Parser Engine] → [ParsedReceipt: Total, Date, Merchant]
↓
[Interactive Review Screen] → [User Corrections] → [SQLite Database]
↓
→ [HomeScreen: List & Cached Thumbnails]
→ [AnalyticsScreen: CustomPainter Donut & Bar Charts]

3.1. Layer Architecture

  • Presentation Layer: HomeScreen with Sliver spending summary and cached thumbnail cards; CameraScreen with gesture tap-to-focus and crop overlay; ReviewScreen for post-scan confirmation; AnalyticsScreen for chart interaction.
  • Service Layer: OcrService handling ML Kit TextRecognizer lifecycle; ReceiptParser pure Dart heuristic regex extractor.
  • Data Layer: DatabaseHelper managing local SQLite database schema, CRUD operations, and fast group-by aggregate queries.

4. Technical Implementation Highlights

4.1. Regex Heuristic Parser Engine (receipt_parser.dart)

Supermarket and restaurant receipts vary significantly. The custom heuristic engine employs a multi-stage extraction pipeline:

  • Total Extraction: Matches Vietnamese keywords (TỔNG CỘNG, THANH TOÁN, THÀNH TIỀN) and English keywords (TOTAL, AMOUNT DUE). Resolves Vietnamese dot thousand separators (150.000 đ → 150000.0) and standard commas (150,000 VND).
  • Date Disambiguation: Prioritizes ISO dates (YYYY-MM-DD) to avoid misinterpreting years as days, followed by Vietnamese slash format (DD/MM/YYYY) and textual Vietnamese dates (Ngày DD tháng MM năm YYYY).
  • Merchant Filtering: Extracts header text while strictly filtering out administrative noise lines such as HÓA ĐƠN BÁN HÀNG, MÃ SỐ THUẾ, phone numbers, and addresses.

4.2. Custom Canvas Visualizations (CustomPainter)

  • Interactive Donut Chart: Parametric sweep angles calculated with (categoryAmount / totalSpending) * 2π * progress. Tapping on any slice calculates the touch polar angle using atan2(dy, dx), dynamically expanding the selected slice and rendering the category name, amount, and percentage in the center circle.
  • Interactive Bar Chart: Renders 7-day spending trends with vertical gradient fills. Tapping on a column calculates the bar slot index, highlights the active column, and displays an exact currency value badge.
